Room photos loaded by "npm run db:seed" for rooms that have no photos yet.
Name them <room number>-<order>.jpg, e.g. 301-1.jpg, 301-2.jpg, 306-1.jpg.
To replace photos already loaded: set REPLACE_ROOM_PHOTOS=true in .env, run npm run db:seed, then remove the setting.
Photos can also be managed one by one under Management > Rooms > Manage.
